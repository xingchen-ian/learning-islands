# 英语学习群岛 · 海外镜像

这是家庭自用学习站（词汇 / 语法 / 考纲词汇 / 语文 / 历史）的**只读镜像**，
部署在 GitHub Pages 上，用于海外访问与灾备。主站托管在腾讯云 CloudBase。

## 关于进度保存

本镜像**不连接云端**。学习进度只写进当前浏览器的 localStorage——
换设备、换浏览器或清理浏览器数据都会丢失。需要跨设备同步请使用主站。

## 内容说明

词汇与语法数据整理自沪教版（五四学制）上海新教材 7A 及配套练习，
考纲词汇表整理自上海市教育考试院公开词汇表，仅供家庭学习使用。

## 重新生成

镜像由源项目根目录的 `build-mirror.sh` 自动生成，请勿直接编辑本目录下的文件——
下次构建会全部覆盖。修改请改源项目，然后重新运行构建脚本。
